# St Mary's Urban Mobility Hub

A React-based travel information web app that helps users plan and compare journeys across public transport, cycling, and walking in London.

## Overview
Urban Mobility Hub was built to solve a common problem: city travellers struggle to compare transport options and get reliable, real-time service information in one place. The app combines static travel guidance with live data from Transport for London (TfL) to support everyday journey planning.

## Features
- **Multi-route React application** with client-side routing across dedicated pages for travel modes, fare estimation, and live updates
- **Fare/cost estimator** — users input distance and travel mode to get an estimated cost range
- **Live TfL service updates** — real-time disruption and status feed pulled from the TfL API
- **API-driven journey planner** — returns route options between a start and end location
- **Nearby stops finder** — surfaces the closest stations/stops to the user
- **Bike hire integration** — live availability/capacity data for shared mobility (Santander Cycles via TfL API)
- **Responsive design** across devices, styled with Bootstrap

## Tech Stack
React · Redux (state management) · Bootstrap · TfL Unified API
