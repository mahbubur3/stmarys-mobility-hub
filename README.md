### `St Mary's Mobility Hub`
React, Redux, Bootstrap - real-time transport dashboard
- Built a React single-page app that consumes the TfL (Transport for London) API to show live transport status and journey information.
- Used Redux to manage application state across components and Bootstrap for a responsive, mobile-friendly layout.
- Structured the app with reusable components and environment-based API key configuration.



### `npm run build`

Builds the production-ready app into the `build` folder.

### `npm test`

Launches the Create React App test runner.

## API Configuration

The project uses the TfL API. Add a key to `.env` as:

```text
REACT_APP_TFL_KEY=your_key_here
```

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).
